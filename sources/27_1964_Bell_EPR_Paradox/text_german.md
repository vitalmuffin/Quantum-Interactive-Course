# I. Einleitung

DAS Paradoxon von Einstein, Podolsky und Rosen [1] wurde als Argument vorgebracht, dass die Quantenmechanik keine vollständige Theorie sein könne, sondern durch zusätzliche Variablen ergänzt werden sollte. Diese zusätzlichen Variablen sollten der Theorie Kausalität und Lokalität wiederherstellen [2]. In dieser Notiz wird diese Idee mathematisch formuliert und als unvereinbar mit den statistischen Vorhersagen der Quantenmechanik gezeigt. Es ist die Anforderung der Lokalität, genauer gesagt, dass das Ergebnis einer Messung auf einem System von Operationen auf einem entfernten System, mit dem es in der Vergangenheit interagiert hat, nicht beeinträchtigt wird, die die wesentliche Schwierigkeit schafft. Es gab Versuche [3] zu zeigen, dass selbst ohne eine solche Separabilitäts- oder Lokalitätsanforderung keine "versteckte Variablen"-Interpretation der Quantenmechanik möglich ist. Diese Versuche wurden anderswo untersucht [4] und als unzureichend erfunden. Außerdem eine Interpretation der verborgenen Variablen der elementaren Quantentheorie [5] explizit konstruiert wurde. Diese spezielle Interpretation hat tatsächlich eine grob nicht-lokale Struktur. Dies ist gemäß dem hier zu beweisenden Ergebnis charakteristisch für jede solche Theorie, die die quantenmechanischen Vorhersagen exakt reproduziert.

# II. Formulierung

Mit dem von Bohm und Aharonov vertretenen Beispiel [6], das EPR-Argument ist folgendes. Betrachten wir ein Paar von Spin-Halbteilchen, die irgendwie im Singlet-Spin-Zustand gebildet werden und sich frei in entgegengesetzte Richtungen bewegen. Messungen können beispielsweise mit Stern-Gerlach-Magneten an ausgewählten Komponenten der Spins durchgeführt werden $\vec{\sigma}_1$ und $\vec{\sigma}_2$. Wenn die Messung der Komponente $\vec{\sigma}_1 \cdot \vec{a}$, wobei $\vec{a}$ ein Einheitsvektor ist, den Wert +1 ergibt, dann wird gemäß der Quantenmechanik die Messung von $\vec{\sigma}_2 \cdot \vec{a}$ muss den Wert -1 ergeben und umgekehrt. Nun stellen wir die Hypothese auf [2], und es scheint zumindest eine Überlegung wert zu sein, dass, wenn die beiden Messungen an weit voneinander entfernten Orten durchgeführt werden, die Orientierung eines Magneten das Ergebnis mit dem anderen nicht beeinflusst. Da wir das Ergebnis der Messung beliebiger gewählter Komponente von im Voraus vorhersagen können $\vec{\sigma}_2$, indem zuvor dieselbe Komponente von gemessen wurde $\vec{\sigma}_1$folgt daraus, dass das Ergebnis einer solchen Messung tatsächlich vorbestimmt sein muss. Da die anfängliche quantenmechanische Wellenfunktion das Ergebnis einer einzelnen Messung nicht bestimmt, impliziert diese Vorbestimmung die Möglichkeit einer vollständigeren Spezifikation des Zustands.

Lassen Sie diese vollständigere Spezifikation mittels von Parametern bewirkt werden $\lambda$. Es ist eine Frage der Gleichgültigkeit, ob $\lambda$ bezeichnet eine einzelne Variable oder eine Menge, oder sogar eine Menge von Funktionen, und ob die Variablen diskret oder stetig sind. Wir schreiben jedoch, als ob $\lambda$ waren ein einziger kontinuierlicher Parameter. Das Ergebnis A der Messung $\vec{\sigma}_1 \cdot \vec{a}$ wird dann bestimmt durch $\vec{a}$ und $\lambda$, und das Messergebnis B $\vec{\sigma}_2 \cdot \vec{b}$ im selben Fall wird bestimmt durch $\vec{b}$ und $\lambda$, und

$$A ( \vec { a } , \lambda ) = \pm 1 , B ( \vec { b } , \lambda ) = \pm 1 .$$

Die vitale Annahme [2] ist das Ergebnis, $B$ für Partikel 2 hängt nicht von der Einstellung ab $\vec { a }$, des Magneten für Teilchen 1, noch $A$ auf $\vec { b }$.

Wenn $\rho ( \lambda )$ ist die Wahrscheinlichkeitsverteilung von $\lambda$ dann der Erwartungswert des Produkts der beiden Komponenten $\vec { \sigma } _ { 1 } \cdot \vec { a }$ und $\vec { \sigma } _ { 2 } \cdot \vec { b }$ ist

$$P ( \vec { a } , \vec { b } ) = \int d \lambda \rho ( \lambda ) A ( \vec { a } , \lambda ) B ( \vec { b } , \lambda )$$

Dies sollte dem quantenmechanischen Erwartungswert entsprechen, der für den Singlet-Zustand lautet

$$< \vec { \sigma } _ { 1 } \cdot \vec { a } \ \vec { \sigma } _ { 2 } \cdot \vec { b } > = - \vec { a } \cdot \vec { b } .$$

Aber es wird gezeigt, dass dies nicht möglich ist.

Manche bevorzugen vielleicht eine Formulierung, in der die verborgenen Variablen in zwei Mengen fallen, mit $A$ abhängig von eins und $B$ andererseits; Diese Möglichkeit ist im obigen Satz enthalten, da $\lambda$ steht für eine beliebige Anzahl von Variablen und deren Abhängigkeiten von $A$ und $B$ sind uneingeschränkt. In einer vollständigen physikalischen Theorie des von Einstein vorgesehenen Typs hätten die verborgenen Variablen dynamische Bedeutung und Bewegungsgesetze; unsere $\lambda$ können dann als Anfangswerte dieser Variablen zu einem geeigneten Zeitpunkt betrachtet werden.

### III. Illustration

Der Beweis des Hauptergebnisses ist recht einfach. Bevor man es jedoch gibt, können einige Beispiele dazu dienen, das Ganze ins rechte Licht zu rücken.

Erstens ist es keine Schwierigkeit, eine versteckte Variable für die Spinmessungen eines einzelnen Teilchens zu liefern. Angenommen, wir haben ein Spin-Halb-Teilchen im reinen Spin-Zustand mit Polarisation, die durch einen Einheitsvektor bezeichnet wird $\vec { p }$. Sei die versteckte Variable (zum Beispiel) ein Einheitsvektor $\vec { \lambda }$ mit einer gleichmäßigen Wahrscheinlichkeitsverteilung über die Hemisphäre $\vec { \lambda } \cdot \vec { p } > 0$. Spezifizieren, dass das Ergebnis der Messung einer Komponente $\vec { \sigma } \cdot \vec { a }$ ist

$$\mathrm { s i g n } \ \vec { \lambda } \cdot \vec { a } ^ { \prime } ,$$

wobei $\vec { a } ^ { \prime }$ ein Einheitsvektor ist, der von $\vec { a }$ und $\vec { p }$ in gewisser Weise zu spezifizieren, und die Vorzeichenfunktion ist $+ 1$ oder $- 1$ entsprechend dem Zeichen seines Arguments. Tatsächlich bleibt das Ergebnis unbestimmt, wann $\lambda \cdot \vec { a } ^ { \prime } = 0$, aber da die Wahrscheinlichkeit dafür null ist, werden wir keine Sonderrezepte dafür erlassen. Durchschnitt über $\vec { \lambda }$ Der Erwartungswert ist

$$< \vec { \sigma } \cdot \vec { a } > = 1 - 2 \theta ^ { \prime } / \pi ,$$

wobei $\theta ^ { \prime }$ ist der Winkel zwischen $\vec { a } ^ { \prime }$ und $\vec { p }$. Angenommen dann, dass $\vec { a } ^ { \prime }$ erhält sich aus $\vec { a }$ durch Rotation in Richtung $\vec { p }$ Bis

$$1 - \frac { 2 \theta ^ { \prime } } { \pi } = \cos \theta$$

wobei $\theta$ ist der Winkel zwischen $\vec { a }$ und $\vec { p }$. Dann haben wir das gewünschte Ergebnis

$$< \vec { \sigma } \cdot \vec { a } > = \cos \theta$$

In diesem einfachen Fall besteht also kein Problem darin, das Ergebnis jeder Messung durch den Wert einer zusätzlichen Variablen bestimmt zu werden und dass die statistischen Merkmale der Quantenmechanik entstehen, weil der Wert dieser Variablen in einzelnen Fällen unbekannt ist.

Zweitens ist es keine Schwierigkeit, in der Form (2) die einzigen Merkmale von (3), die häufig in verbalen Diskussionen dieses Problems verwendet werden, wiederzugeben:

$$\left. \begin{array}{l} P(\vec{a}, \vec{a}) = -P(\vec{a}, -\vec{a}) = -1 \\ P(\vec{a}, \vec{b}) = 0 \text{ if } \vec{a} \cdot \vec{b} = 0 \end{array} \right\} \tag{8}$$

Zum Beispiel, sei $\lambda$ sei nun Einheitsvektor $\vec{\lambda}$, mit einer gleichmäßigen Wahrscheinlichkeitsverteilung über alle Richtungen, und nehmen

$$\left. \begin{array}{l} A(\vec{a}, \vec{\lambda}) = \operatorname{sign} \vec{a} \cdot \vec{\lambda} \\ B(a, b) = -\operatorname{sign} \vec{b} \cdot \vec{\lambda} \end{array} \right\} \tag{9}$$

Das ergibt

$$P(\vec{a}, \vec{b}) = -1 + \frac{2}{\pi} \theta, \tag{10}$$

wobei $\theta$ ist der Winkel zwischen $a$ und $b$, und (10) besitzt die Eigenschaften (8). Zum Vergleich betrachtet man das Ergebnis einer modifizierten Theorie [6] wobei der reine Singlet-Zustand im Laufe der Zeit durch eine isotrope Mischung von Produktzuständen ersetzt wird; dies ergibt die Korrelationsfunktion

$$- \frac{1}{3} \vec{a} \cdot \vec{b} \tag{11}$$

Experimentell ist es wahrscheinlich weniger einfach, (10) von (3) zu unterscheiden als (11) von (3).

Im Gegensatz zu (3) ist die Funktion (10) am Minimalwert nicht stationär $-1$ (bei $\theta = 0$). Es ist zu erkennen, dass dies charakteristisch für Funktionen vom Typ (2) ist.

Drittens und schließlich gibt es keine Schwierigkeiten, die quantenmechanische Korrelation (3) zu reproduzieren, wenn die Ergebnisse $A$ und $B$ in (2) dürfen sich auf $\vec{b}$ und $\vec{a}$ jeweils sowie auf $\vec{a}$ und $\vec{b}$. Zum Beispiel ersetzen $\vec{a}$ in (9) durch $\vec{a}'$, erhalten aus $\vec{a}$ durch Rotation in Richtung $\vec{b}$ Bis

$$1 - \frac{2}{\pi} \theta' = \cos \theta,$$

wobei $\theta'$ ist der Winkel zwischen $\vec{a}'$ und $\vec{b}$. Für gegebene Werte der verborgenen Variablen hängen die Messergebnisse mit einem Magneten nun von der Einstellung des entfernten Magneten ab, was genau das ist, was wir vermeiden möchten.

### IV. Widerspruch

Das Hauptergebnis wird nun bewiesen. Weil $\rho$ ist eine normalisierte Wahrscheinlichkeitsverteilung,

$$\int d\lambda \rho(\lambda) = 1, \tag{12}$$

und aufgrund der Eigenschaften (1), $P$ in (2) darf nicht kleiner als sein $-1$. Es kann reichen $-1$ bei $\vec{a} = \vec{b}$ nur wenn

$$A(\vec{a}, \lambda) = -B(\vec{a}, \lambda) \tag{13}$$

außer an einer Menge von Punkten $\lambda$ von null Wahrscheinlichkeit. Unter dieser Annahme kann (2) umgeschrieben werden

$$P(\vec{a}, \vec{b}) = -\int d\lambda \rho(\lambda) A(\vec{a}, \lambda) A(\vec{b}, \lambda). \tag{14}$$

Daraus folgt, dass $\vec{c}$ ist ein weiterer Einheitsvektor

$$\begin{array}{l} P(\vec{a}, \vec{b}) - P(\vec{a}, \vec{c}) = - \int d\lambda\rho(\lambda) [A(\vec{a}, \lambda) A(\vec{b}, \lambda) - A(\vec{a}, \lambda) A(\vec{c}, \lambda)] \\ = \int d\lambda\rho(\lambda) A(\vec{a}, \lambda) A(\vec{b}, \lambda) [A(\vec{b}, \lambda) A(\vec{c}, \lambda) - 1] \end{array}$$

unter Verwendung von (1), woraus

$$|P(\vec{a}, \vec{b}) - P(\vec{a}, \vec{c})| \leq \int d\lambda\rho(\lambda) [1 - A(\vec{b}, \lambda) A(\vec{c}, \lambda)]$$

Der zweite Term rechts ist $P(\vec{b}, \vec{c})$, von wo aus

$$1 + P(\vec{b}, \vec{c}) \geq |P(\vec{a}, \vec{b}) - P(\vec{a}, \vec{c})| \tag{15}$$

Außer $P$ ist konstant, die rechte Seite ist im Allgemeinen von Ordnung $|\vec{b}-\vec{c}|$ für kleine $|\vec{b}-\vec{c}|$. Daher $P(\vec{b}, \vec{c})$ kann beim Minimalwert nicht stationär sein ($-1$ bei $\vec{b} = \vec{c}$) und kann nicht dem quantenmechanischen Wert (3) entsprechen.

Auch kann die quantenmechanische Korrelation (3) nicht beliebig eng durch die Form (2) angenähert werden. Der formale Beweis dafür kann wie folgt dargestellt werden. Wir würden uns keine Sorgen um das Versagen der Approximation an isolierten Punkten machen, daher betrachten wir statt (2) und (3) die Funktionen

$$\overline{P}(\vec{a}, \vec{b}) \text{ and } \overline{-\vec{a} \cdot \vec{b}}$$

wobei die Bar die unabhängige Durchschnittswertung von bezeichnet $P(\vec{a}', \vec{b}')$ und $-\vec{a}' \cdot \vec{b}'$ über Vektoren $\vec{a}'$ und $\vec{b}'$ innerhalb von festgelegten kleinen Winkeln von $\vec{a}$ und $\vec{b}$. Angenommen, dass für alle $\vec{a}$ und $\vec{b}$ Die Differenz ist beschränkt durch $\epsilon$:

$$|\overline{P}(\vec{a}, \vec{b}) + \vec{a} \cdot \vec{b}| \leq \epsilon \tag{16}$$

Dann wird gezeigt, dass $\epsilon$ kann nicht willkürlich klein gemacht werden.

Angenommen, dass für alle $a$ und $b$

$$|\overline{\vec{a} \cdot \vec{b}} - \vec{a} \cdot \vec{b}| \leq \delta \tag{17}$$

Dann ab (16)

$$|\overline{P}(\vec{a}, \vec{b}) + \vec{a} \cdot \vec{b}| \leq \epsilon + \delta \tag{18}$$

Aus (2)

$$\overline{P}(\vec{a}, \vec{b}) = \int d\lambda\rho(\lambda) \overline{A}(\vec{a}, \lambda) \overline{B}(\vec{b}, \lambda) \tag{19}$$

wobei

$$|\overline{A}(\vec{a}, \lambda)| \leq 1 \text{ and } |\overline{B}(\vec{b}, \lambda)| \leq 1 \tag{20}$$

Aus (18) und (19), mit $\vec{a} = \vec{b}$,

$$d\lambda\rho(\lambda) [\overline{A}(\vec{b}, \lambda) \overline{B}(\vec{b}, \lambda) + 1] \leq \epsilon + \delta \tag{21}$$

Von (19)

$$\begin{array}{l} \overline{P}(\vec{a}, \vec{b}) - \overline{P}(\vec{a}, \vec{c}) = \int d\lambda\rho(\lambda) [\overline{A}(\vec{a}, \lambda) \overline{B}(\vec{b}, \lambda) - \overline{A}(\vec{a}, \lambda) \overline{B}(\vec{c}, \lambda)] \\ = \int d\lambda\rho(\lambda) \overline{A}(\vec{a}, \lambda) \overline{B}(\vec{b}, \lambda) [1 + \overline{A}(\vec{b}, \lambda) \overline{B}(\vec{c}, \lambda)] \\ - \int d\lambda\rho(\lambda) \overline{A}(\vec{a}, \lambda) \overline{B}(\vec{c}, \lambda) [1 + \overline{A}(\vec{b}, \lambda) \overline{B}(\vec{b}, \lambda)] \end{array}$$

Mit (20) dann

$$| \bar{P}(\vec{a}, \vec{b}) - \bar{P}(\vec{a}, \vec{c}) | \leq \int d\lambda \alpha(\lambda) [1 + \bar{A}(\vec{b}, \lambda) \bar{B}(\vec{c}, \lambda)] + \int d\lambda \rho(\lambda) [1 + \bar{A}(\vec{b}, \lambda) \bar{B}(\vec{b}, \lambda)]$$

Dann mit (19) und 21)

$$| \bar{P}(\vec{a}, \vec{b}) - \bar{P}(\vec{a}, \vec{c}) | \leq 1 + \bar{P}(\vec{b}, \vec{c}) + \epsilon + \delta$$

Abschließend, unter Verwendung von (18),

$$| \vec{a} \cdot \vec{c} - \vec{a} \cdot \vec{b} | - 2(\epsilon + \delta) \leq 1 - \vec{b} \cdot \vec{c} + 2(\epsilon + \delta)$$

oder

$$4(\epsilon + \delta) \geq | \vec{a} \cdot \vec{c} - \vec{a} \cdot \vec{b} | + \vec{b} \cdot \vec{c} - 1 \tag{22}$$

Nehmen wir zum Beispiel $\vec{a} \cdot \vec{c} = 0$, $\vec{a} \cdot \vec{b} = \vec{b} \cdot \vec{c} = 1/\sqrt{2}$ Dann

$$4(\epsilon + \delta) \geq \sqrt{2} - 1$$

Daher gilt für kleine endliche $\delta$, $\epsilon$ Darf nicht willkürlich klein sein.

Daher kann der quantenmechanische Erwartungswert weder genau noch beliebig eng in der Form (2) dargestellt werden.

# V. Verallgemeinerung

Das oben betrachtete Beispiel hat den Vorteil, dass es wenig Vorstellungskraft erfordert, die tatsächlich durchgeführten Messungen vorzustellen. Formeller, unter der Annahme [7] dass jeder Hermitsche Operator mit einer vollständigen Menge von Eigenzuständen eine "Beobachtbare" ist, lässt sich das Ergebnis leicht auf andere Systeme übertragen. Wenn die beiden Systeme Zustandsräume größer als 2 haben, können wir immer zweidimensionale Unterräume betrachten und in ihrem direkten Produkt Operatoren definieren $\vec{\sigma}_1$ und $\vec{\sigma}_2$ formal analog zu den oben verwendeten und die für Zustände außerhalb des Produktteilraums null sind. Dann sind für mindestens einen quantenmechanischen Zustand, den "Singlet"-Zustand in den kombinierten Teilräumen, die statistischen Vorhersagen der Quantenmechanik mit separabler Vorbestimmung unvereinbar.

# VI. Fazit

In einer Theorie, in der Parameter zur Quantenmechanik hinzugefügt werden, um die Ergebnisse einzelner Messungen zu bestimmen, ohne die statistischen Vorhersagen zu ändern, muss es einen Mechanismus geben, bei dem die Einstellung eines Messgeräts die Messung eines anderen Instruments beeinflussen kann, so fern sie auch sein mag. Außerdem muss das betroffene Signal sich augenblicklich ausbreiten, sodass eine solche Theorie nicht Lorentz-invariant sein kann.

Natürlich ist die Situation anders, wenn die quantenmechanischen Vorhersagen nur begrenzt gültig sind. Theoretisch könnten sie nur auf Experimente angewendet werden, bei denen die Einstellungen der Instrumente ausreichend im Voraus getroffen werden, um durch den Austausch von Signalen mit einer Geschwindigkeit kleiner als oder gleich der des Lichts eine gegenseitige Verbindung herzustellen. In diesem Zusammenhang wurden Experimente der Art von Bohm und Aharonov vorgeschlagen [6], bei der die Einstellungen während des Flugs der Teilchen geändert werden, sind entscheidend.
