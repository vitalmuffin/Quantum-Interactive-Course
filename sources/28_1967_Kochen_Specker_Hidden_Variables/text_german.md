# *Das Problem der verborgenen Variablen in der Quantenmechanik*

SIMON KOCHEN & E. P. SPECKER

*Kommuniziert von A. M. GLEASON*

**0. Einleitung.** Vierzig Jahre nach dem Aufkommen der Quantenmechanik bleibt das Problem der versteckten Variablen, also die Möglichkeit, die Quantentheorie in eine klassische Theorie einzubetten, ein kontroverses und unklares Thema. Während für die meisten Physiker die Möglichkeit einer klassischen Neuinterpretation der Quantenmechanik gering und vielleicht irrelevant für aktuelle Probleme bleibt, hat eine Minderheit das Thema während dieses Zeitraums lebendig gehalten. (Siehe Freistadt [5] für eine Übersicht des Problems und eine umfassende Bibliographie bis 1957.) Was die Ergebnisse betrifft, gibt es einerseits angebliche Beweise für die Nichtexistenz verborgener Variablen, insbesondere von Neumanns Beweis, und andererseits verschiedene Versuche, verborgene Variablen einzuführen, wie de Broglie [4] und Bohm [1] und [2]. Eine der Schwierigkeiten bei der Bewertung dieser widersprüchlichen Ergebnisse besteht darin, dass kein exaktes mathematisches Kriterium vorliegt, das es ermöglicht, den Erfolgsgrad dieser Vorschläge zu beurteilen.

Das Hauptziel dieser Arbeit ist es, einen Beweis für die Nichtexistenz versteckter Variablen zu liefern. Dies erfordert, dass wir zumindest eine präzise, notwendige Bedingung für ihre Existenz angeben. Dies wird in den Abschnitten 1 und 2 umgesetzt. Die Vorschläge in der Literatur für eine klassische Neuinterpretation führen üblicherweise einen Phasenraum verborgener Reinzustände ein, ähnlich wie die statistische Mechanik. Der Versuch zeigt sich dann als erfolgreich, da der quantenmechanische Durchschnitt einer Beobachtbarkeit gleich dem Phasenraummittelwert ist. Diese statistische Bedingung berücksichtigt jedoch nicht die algebraische Struktur der quantenmechanischen Observablen. Eine minimale solche Struktur ergibt sich dadurch, dass einige Observablen Funktionen anderer sind. Diese Struktur ist unabhängig von der jeweiligen Theorie und sollte in einer klassischen Neuinterpretation bewahrt werden. Dass dies durch die obige statistische Bedingung nicht gewährleistet ist, lässt sich leicht zeigen, indem man einen Phasenraum konstruiert, in dem die statistische Bedingung erfüllt ist, die quantenmechanischen Observablen jedoch als unabhängige Zufallsvariablen über den Raum interpretiert werden.

Konzept der partiellen Algebra. Die Menge der quantenmechanischen Observablen, die als Operatoren auf dem Hilbertraum betrachtet werden, bildet eine partielle Algebra, wenn wir die Operationen von Summe und Produkt nur dann definieren, wenn die Operatoren kommutieren. Eine notwendige Bedingung für die Existenz verborgener Variablen ist also, dass diese partielle Algebra in eine kommutative Algebra eingebettet sein kann (wie die Algebra aller reellwertigen Funktionen auf einem Phasenraum). In den Abschnitten 3 und 4 wird gezeigt, dass es eine endliche partielle Algebra quantenmechanischer Observablen gibt, für die keine solche Einbettung existiert. Die physikalische Beschreibung dieses Ergebnisses kann intuitiv verstanden werden, ganz unabhängig von der eingeführten formalen Maschinerie. Ein elektrisches Feld rhombischer Symmetrie kann auf ein Orthohelatom in seinem niedrigsten Energiezustand in einer beliebigen von einer festgelegten endlichen Anzahl von Richtungen angewendet werden. Die vorgeschlagene klassische Interpretation muss dann die resultierende Änderung des Energiezustands des Atoms in jeder dieser Richtungen vorhersagen. Für jede solche Vorhersage existiert in dieser spezifizierten Menge eine Richtung, in der das Feld so angewendet werden kann, dass der vorhergesagte Wert durch den experimentell gemessenen Wert widerlegt wird.

Der letzte Abschnitt behandelt die Logik der Quantenmechanik. Dort wird bewiesen, dass das zuvor betrachtete Einbettungsproblem äquivalent zur Frage ist, ob die Logik der Quantenmechanik im Wesentlichen mit der klassischen Logik identisch ist. Die genaue Bedeutung dieser Aussage ist in diesem Abschnitt angegeben. Grob gesagt eine Aussagenformel $\psi(x_1, \cdots, x_n)$ ist in der Quantenmechanik gültig, wenn für jede "sinnvolle" Substitution quantenmechanischer Aussagen $P_i$ für die Variablen $x_i$ Diese Formel ist wahr, wobei eine sinnvolle Substitution eine ist, so dass die Aussagen $P_i$ sind nur durch die logischen Konnektiven in verbunden $\psi(P_1, \cdots P_n)$ wenn sie gleichzeitig messbar sind. Aus unseren Ergebnissen folgt dann, dass es eine Formel gibt $\varphi(x_1, \cdots, x_{16})$ was eine klassische Tautologie ist, aber für eine sinnvolle Substitution quantenmechanischer Aussagen falsch gilt. In diesem Sinne unterscheidet sich die Logik der Quantenmechanik von der klassischen Logik. Das positive Problem der Beschreibung der Quantenlogik wurde bei Kochen und Specker untersucht [10] und [11].

In Abschnitt 5 wurde der vorliegende Beweis mit von Neumanns bekanntem Beweis der Nichtexistenz verborgener Variablen verglichen. Von Neumanns Beweis basiert im Wesentlichen auf der Nichtexistenz einer reellwertigen Funktion auf der Menge der quantenmechanischen Observablen, die multiplikativ auf kommutierende Observablen und linear ist. In unserem Beweis zeigen wir die Nichtexistenz einer reellwertigen Funktion, die sowohl multiplikativ als auch linear nur auf kommutierenden Observablen ist. Daher ist unser Ergebnis formal stärker als das von Neumanns. In Abschnitt 5 versuchen wir zu zeigen, dass dieser Unterschied wesentlich ist. Wir zeigen, dass das von-Neumann-Kriterium auf ein einzelnes Spin-Teilchen anwendbar ist $\frac{1}{2}$, was impliziert, dass es keine klassische Beschreibung dieses Systems gibt. Andererseits widersprechen wir dieser Schlussfolgerung, indem wir ein klassisches Modell eines Spin konstruieren $\frac{1}{2}$ Partikel. Dies geschieht, indem die partielle Algebra selbstadjungierter Operatoren auf einem zweidimensionalen komplexen Hilbertraum in die Algebra reellwertiger Funktionen auf einem geeigneten Phasenraum eingebettet wird, sodass die statistische Bedingung erfüllt ist.

1. Diskussion des Problems. Für unsere Zwecke ist es praktisch, eine physikalische Theorie im folgenden Rahmen zu beschreiben. Wir erhalten eine Menge $\mathcal{O}$ genannt die Menge der Observablen und eine Menge $S$ genannt die Menge der Zustände. Zusätzlich haben wir eine Funktion $P$ die jedem Observablen zuweist $A$ und jeder Zustand $\psi$ ein Wahrscheinlichkeitsmaß $P_{A\psi}$ Auf der realen Linie $\mathbf{R}$. Körperlich gesehen, wenn $U$ ist eine Teilmenge von $\mathbf{R}$ was bezüglich messbar ist $P_{A\psi}$, dann $P_{A\psi}(U)$ bezeichnet die Wahrscheinlichkeit, dass die Messung von $A$ für ein System im Bundesstaat $\psi$ ergibt einen Wert, der in liegt $U$. Daraus erhalten wir auf übliche Weise die Erwartung des Beobachtbaren $A$ für den Staat $\psi$,

$$\text{Exp}_\psi(A) = \int_{-\infty}^{\infty} \lambda \, dP_{A\psi}(\lambda).$$

Staaten werden im Allgemeinen in zwei Arten unterteilt: Reine Staaten und gemischte Staaten. Grob gesagt beschreiben die reinen Zustände eine maximal mögliche Wissensmenge in der Theorie über das betreffende physikalische System; Die gemischten Zustände liefern nur unvollständige Informationen und beschreiben unsere Unwissenheit über den genauen reinen Zustand, in dem sich das System tatsächlich befindet.

Wir veranschaulichen diese Bemerkungen mit einem Beispiel aus der newtonschen Mechanik. Angenommen, wir erhalten ein System von $N$ Partikel. Dann ist jeder reine Zustand $\psi$ des Systems ist gegeben durch eine $6N$-Tupel $(q_1, \dots, q_{2N}, p_1, \dots, p_{2N})$ reelle Zahlen, die die Koordinaten der Position und des Impulses der Teilchen angeben. In diesem Fall gilt die Wahrscheinlichkeit $P_{A\psi}$ Jeder Beobachtbarkeit ist ein Atommaß zugewiesen, das sich auf eine einzelne reelle Zahl konzentriert $a$. Das heißt, $P_{A\psi}(U) = 1$ wenn $a \in U$ und $P_{A\psi}(U) = 0$ wenn $a \notin U$. Daher gilt: Wenn wir den Phasenraum einführen $\Omega$ von reinen Zuständen, die wir hier mit einer Teilmenge von identifizieren können $6N$-dimensionaler euklidischer Raum, dann jedes Observable $A$ wird mit einer reellwertigen Funktion assoziiert $f_A : \Omega \to \mathbf{R}$ gegeben durch $f_A(\psi) = a$.

Wenn $N$ groß ist, ist es nicht möglich, den genauen reinen Zustand des Systems zu bestimmen. In diesem Fall greifen wir auf den Begriff eines gemischten Zustands zurück, der nur die Wahrscheinlichkeit ergibt, dass das System sich in einem reinen Zustand befindet, der in einem Bereich von liegt $\Omega$. Daraus folgt unmittelbar, dass das Wahrscheinlichkeitsmaß $P_{A\psi}$ einem Observablen zugewiesen $A$ und gemischten Zustand $\psi$ ist gegeben durch die Formel

$$(1) \quad P_{A\psi}(U) = \mu_\psi(f_A^{-1}(U)).$$

Somit haben wir

$$(2) \quad \text{Exp}_\psi(A) = \int_\Omega f_A(\omega) \, d\mu_\psi(\omega).$$

Aus der Definition einer partiellen Algebra folgt unmittelbar, dass, wenn $D$ ist eine Menge paarweiser kompatisierbarer Elemente von $A$ dann die Menge $D$ erzeugt eine kommutative Algebra in $A$.

Wir haben den Begriff einer partiellen Algebra über einem beliebigen Körper definiert $K$ Aber es gibt zwei Fälle, die für uns von Interesse sind. Das erste ist das Feld $\mathbf{R}$ der reellen Zahlen und die zweite ist der Körper $Z_2$ von zwei Elementen. Für den Fall einer partiellen Algebra über $Z_2$ wir können die boolesche Operationen in Bezug auf die Ringoperationen auf die übliche Weise definieren: $a \cap b = ab$, $a \cup b = a + b - ab$, $a' = 1 - a$. Daraus folgt, dass wenn $a_i \circ a_j$, $1 \leq i, j \leq 3$, dann die Polynome in $a_1, a_2, a_3$ bildet eine boolesche Algebra. Wir nennen eine partielle Algebra über $Z_2$ a *partielle Boolesche Algebra*. Es ist klar, wie wir diesen Begriff direkt im Hinblick auf die Operationen definieren können $\cap, \cup, \prime$. Was eine partielle Boolesche Algebra für unsere Zwecke wichtig macht, ist, dass die Menge der idempotenten Elemente einer partiellen Algebra $\mathfrak{R}$ bildet eine partielle Boolesche Algebra. Dies ist ein Gegenstück zur bekannten Tatsache, dass die Menge der Idempotenten einer kommutativen Algebra eine boolesche Algebra bildet.

Wir betrachten einige Beispiele partieller Algebren. Lass $H(U^\alpha)$ die Menge aller selbstadjungierten Operatoren auf einem komplexen Hilbertraum sein $U^\alpha$ von Dimension $\alpha$.
